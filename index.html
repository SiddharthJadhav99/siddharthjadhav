    How I build

    The habits behind the numbers. Each one came from a real incident, and the case studies show where.

    • LLMs where judgment lives

      Agents talk to people. Routing, lookups and orders are deterministic code that can be tested and can’t hallucinate.

    • Evidence before change

      Traces, query plans and logs first, then the fix. I don’t re-propose a theory a test has already ruled out.

    • Idempotent by default

      Migrations, seeds and replayed requests are all safe to run twice, because offline clients and retries will run them twice.

    • One source of truth per rule

      A rule lives in one helper, so two screens can never disagree about it.

    • Governance outside the agent

      Policy, moderation and identity live at a gateway, not inside prompts that a model can talk its way around.

    • Leave a paved road

      Deploy, rollback and test tooling go back into the shared template, so the next team starts ahead.

    I also work daily with AI coding agents. Conventions and decisions are written down so the agent, the reviewers and the next engineer all work from the same context.
